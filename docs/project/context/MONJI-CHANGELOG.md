# Registered Context Package

## ثبت رسمی بسته Context پروژه

Date:

2026-07-26

تاریخ ثبت این تغییر و ایجاد نقطه شروع رسمی استفاده از Context Package.


Task:

TASK-0000-C

شناسه فعالیت مربوط به ثبت و استانداردسازی Context Package.


Change Type:

Governance / Documentation

نوع تغییر:
تغییر در قوانین مدیریت پروژه و مستندات، بدون اثر روی کد اجرایی.


Summary:

Created and registered Monji Context Package as the standard starting context for new development chats.

خلاصه:
بسته Context پروژه Monji ایجاد شد تا نقطه شروع استاندارد برای Chatهای جدید توسعه باشد.


Context Package:

- MONJI-CONTEXT.md
- MONJI-TECHNICAL-MAP.md
- MONJI-CHANGELOG.md

معرفی فایل‌ها:

MONJI-CONTEXT.md:
وضعیت کلی پروژه، قوانین اصلی، تیم‌ها، اولویت فعلی و محدودیت‌های مهم را نگهداری می‌کند.

MONJI-TECHNICAL-MAP.md:
نقشه فنی سطح بالا از ساختار Frontend، Backend و نحوه ارجاع به مستندات تخصصی است.

MONJI-CHANGELOG.md:
ثبت تغییرات مهم پروژه که روی Context، تصمیم‌ها یا مستندات اثر دارند.


Purpose:

Reduce repeated documentation loading for new development chats while keeping detailed source documents as the project source of truth.

هدف:
کاهش نیاز به بارگذاری مکرر تمام مستندات در Chatهای جدید، در حالی که فایل‌های اصلی پروژه همچنان مرجع معتبر باقی می‌مانند.


Impact:

Frontend:

Documentation only

تأثیر:
فقط در بخش مستندات است و هیچ تغییری در کد Frontend ایجاد نمی‌کند.


Backend:

No Impact

تأثیر:
هیچ تغییری در Backend ایجاد نشده است.


Database:

No Impact

تأثیر:
هیچ تغییر یا Migration دیتابیسی انجام نشده است.


API:

No Impact

تأثیر:
هیچ تغییری در قراردادها یا سرویس‌های API ایجاد نشده است.


Security:

No Impact

تأثیر:
هیچ تغییری در کنترل‌های امنیتی یا دسترسی‌ها ایجاد نشده است.


Context Impact:

MONJI-CONTEXT established as the standard chat starting point.

تأثیر روی Context:
از این مرحله MONJI-CONTEXT به‌عنوان نقطه شروع استاندارد Chatهای توسعه استفاده خواهد شد.


Technical Documentation Impact:

None

تأثیر روی مستندات فنی:
مستندات تخصصی اصلی بدون تغییر باقی می‌مانند.
