# Feature Task Template

## Purpose

این سند قالب استاندارد تعریف Feature Task در پروژه Monji است.

هدف:

- ایجاد فرآیند یکسان برای شروع توسعه
- جلوگیری از تغییرات بدون بررسی
- مشخص کردن Scope قبل از Implementation
- کنترل Risk تغییرات
- آماده‌سازی Task برای Review و Merge

هر Feature یا Change مهم باید قبل از شروع توسعه با این قالب تعریف شود.
